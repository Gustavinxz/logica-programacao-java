# ☕ Programação Java - Jornada de Estudos 

Este repositório é dedicado ao registro da minha jornada de aprendizado na linguagem **Java**. Aqui eu armazeno exercícios práticos, desafios de lógica e pequenos sistemas desenvolvidos durante meus estudos. 

O objetivo principal não é entregar um projeto único e finalizado, mas sim documentar minha evolução diária, aprimorando o raciocínio lógico, a estruturação de código e construindo uma base técnica sólida para atuar com desenvolvimento e Qualidade de Software.

---

## 🚀 Tecnologias e Ferramentas
* **Java (JDK 21)**
* **VS Code / IntelliJ IDEA**
* **Git & GitHub**

---

## 📂 O que você vai encontrar por aqui?

Este repositório está em constante expansão. Conforme avanço nos estudos, novos pacotes e desafios são adicionados à pasta `src`. 

O escopo abrange desde a sintaxe básica até implementações mais complexas. Alguns exemplos do que costumo explorar e registrar aqui incluem:

* **Fundamentos e Tipos de Dados:** Lógica matemática, conversores de unidades e manipulação de variáveis.
* **Controle de Fluxo:** Estruturação de regras de negócio simples, validações e sistemas de decisão usando condicionais (`if`, `else`, `switch`).
* **Estruturas de Repetição:** Automação de tarefas, como calculadoras iterativas, loops de validação de login e sistemas de cadastro contínuo (`for`, `while`, `do-while`).
* **Manipulação de Textos e Padrões:** Uso avançado da classe String e expressões regulares (Regex) para atividades práticas, como validação de CPFs, checagem de força de senhas e extração de dados.
* **... e muito mais pela frente:** O repositório continuará crescendo para englobar Programação Orientada a Objetos (POO), Estruturas de Dados, Tratamento de Exceções, etc.
